## Key Research Findings

| Objective | Metric / Finding | Strategic Insight |
| :--- | :--- | :--- |
| **Top Format by Reach** | **Reel** (59,256 median views) | Drives top-of-funnel discovery (2.4x reach multiplier over photos). |
| **Top Format by Engagement** | **Carousel** (9.64% engagement rate) | Drives interaction depth and dwell time across multiple slides. |
| **Hashtag Sweet Spot** | **11–15 hashtags** (52,140 median views) | Optimal indexing; >20 hashtags correlates with 54% reach decline. |
| **Peak Posting Window** | **Tuesday & Sunday (18:00–20:00)** | Evening slots produce highest average engagement (up to 7.8%). |
| **Breakout Posts** | **39 posts** (>3x median reach) | Reels represent **56.4%** of all viral breakout posts. |

## Setup and Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ronaksarda/edav-sem-end-project.git
   cd edav-sem-end-project
   ```

2. **Install dependencies:**
   ```bash
   pip install numpy pandas matplotlib seaborn jupyter python-docx
   ```

   ```bash
   jupyter notebook instagram_engagement_analysis.ipynb
   ```
